# Sk Obaidul Islam — Portfolio

Static portfolio site (black & pink). No build step.

## Deploy on GitHub Pages
1. Create a new repository and upload everything in this folder (`index.html`, `assets/`, `README.md`) to the root.
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Your site will be live at `https://<username>.github.io/<repo>/`.

## Structure
- `index.html` — the full site
- `assets/` — photos, CV page images and the downloadable CV PDF
